# Caravans

Trade spare goods for science or useful supplies by sending caravans beyond the map.

## How it works

- Build a **Caravan Post** (in Storage) and connect it to the map edge with a road.
- Choose a trade and a worker will load the caravan before it sets off. Trips take time, and a caravan may not make it back.
- When a caravan returns, it brings its science points and/or goods to the post.
- The post can't send another caravan if there's no route to the map edge or all caravans are away.

## Requirements

Timberborn 1.1.0 or later.

## Building

Built with the [Timberborn modding tools](https://github.com/mechanistry/timberborn-modding). Place this folder in `Assets/Mods/` and build with the Mod Builder.
