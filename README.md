# Caravans

Send surplus goods off the map with caravans in exchange for science points or rare goods.

## How it works

- Build a **Caravan Post** (in Storage) and connect it by road to the map edge.
- A worker loads a caravan using one of the trade recipes. The caravan stays away for a set time and may be lost.
- On return, science points and/or goods are delivered to the post.
- Without a road to the map edge, or with all caravans away, the post cannot dispatch.

## Requirements

Timberborn 1.1.0 or later.

## Building

Built with the [Timberborn modding tools](https://github.com/mechanistry/timberborn-modding). Place this folder in `Assets/Mods/` and build with the Mod Builder.
